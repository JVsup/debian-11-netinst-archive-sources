# debian-11-netinst-archive-sources

Debian 11 (amd64) netinst ISO with preconfigured APT sources pointing to archive.debian.org for convenience.

## Download

- [Debian 11.11.0 amd64 netinst ISO](https://github.com/JVsup/debian-11-netinst-archive-sources/releases/download/v11.11.0-archive/debian-11.11.0-amd64-netinst-archive.iso)
- [SHA-256 checksum](https://github.com/JVsup/debian-11-netinst-archive-sources/releases/download/v11.11.0-archive/debian-11.11.0-amd64-netinst-archive.iso.sha256)

Download both files into the same directory, then verify the image:

```sh
sha256sum -c debian-11.11.0-amd64-netinst-archive.iso.sha256
```
